# After Launch Roadmap

These are not blockers for initial public web app deployment, but recommended for a serious commercial launch.

1. Phone OTP login via Supabase phone auth.
2. Maps and geocoding with Google Maps or Mapbox.
3. In-app chat with message moderation.
4. Payment gateway integration.
5. CNIC/driver-license verification workflow.
6. Admin vehicle verification documents.
7. Push notifications.
8. Terms of service, privacy policy, safety policy.
9. Abuse prevention/rate limits via Supabase Edge Functions.
10. Native Android/iOS wrapper with Capacitor.
